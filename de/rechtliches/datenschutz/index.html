Hosting und Bereitstellung der Website
#

Diese Website wird als statische Website über GitHub Pages bereitgestellt. Beim Aufruf der Website werden technisch erforderliche Zugriffsdaten verarbeitet, insbesondere:

  • IP-Adresse
  • Datum und Uhrzeit des Zugriffs
  • aufgerufene Seiten bzw. Dateien
  • Referrer-URL
  • Browser- und Geräteinformationen
  • Statuscodes

Die Verarbeitung erfolgt zum Zweck der technischen Bereitstellung der Website, zur Stabilität und zur Abwehr von Missbrauch oder Angriffen.

Wir betreiben keine eigenen Webserver und führen keine eigenen Server-Logfiles. Soweit technische Zugriffsdaten protokolliert werden, geschieht dies im Rahmen des Hostings durch GitHub.

Im Zusammenhang mit dem Hosting kann es auch zu einer Verarbeitung personenbezogener Daten in Drittländern, insbesondere in den USA, kommen. GitHub weist darauf hin, dass Daten auch in den USA verarbeitet werden können, und nennt in diesem Zusammenhang insbesondere Standardvertragsklauseln sowie das EU-U.S. Data Privacy Framework als mögliche Transfermechanismen.

Cookies und ähnliche Technologien
#

Wir setzen derzeit keine Cookies zu Analyse-, Marketing- oder Werbezwecken ein.

Allerdings verwendet diese Website für einzelne Funktionen den LocalStorage deines Browsers. Dabei können einfache Statuswerte gespeichert und ausgelesen werden, zum Beispiel, ob in diesem Browser ein bestimmter Beitrag bereits aufgerufen oder mit „Gefällt mir“ markiert wurde. Diese Informationen werden lokal in deinem Browser gespeichert und können gelöscht werden, wenn du deinen Browser-Cache oder gespeicherte Website-Daten entfernst. Je nach deinen Browsereinstellungen oder bei Nutzung eines privaten Modus können diese Daten auch automatisch beim Schließen des Browsers gelöscht werden.

Nutzung von Firebase / Cloud Firestore
#

Für einzelne Funktionen dieser Website verwenden wir Firebase / Cloud Firestore von Google. Dabei nutzen wir ausschließlich Cloud Firestore, um technische Informationen für die Anzeige von Aufrufzahlen und „Gefällt mir“-Angaben bei einzelnen Artikeln zu verarbeiten.

Wir verwenden Firebase nicht für Analyse-, Werbe- oder Marketingzwecke und nutzen keine weiteren Firebase-Dienste wie etwa Analytics.

Im Browser des Nutzers werden über den LocalStorage einfache Statuswerte gespeichert. Diese dienen dazu, innerhalb des jeweils verwendeten Browsers nachzuhalten, ob ein bestimmter Artikel bereits aufgerufen wurde oder ob für einen Artikel bereits ein „Gefällt mir“ gesetzt wurde. Dadurch soll insbesondere verhindert werden, dass dieselbe Aktion im selben Browser unnötig mehrfach berücksichtigt wird.

Diese Informationen werden lokal im Browser gespeichert und enthalten nach unserer Konzeption keine Klarnamen oder direkten Kontaktangaben. Sie können gelöscht werden, wenn der Browser-Cache oder gespeicherte Website-Daten entfernt werden. Je nach Browsereinstellung oder bei Nutzung eines privaten Modus können diese Daten auch automatisch beim Schließen des Browsers gelöscht werden.

Im Zusammenhang mit der Nutzung von Firebase / Cloud Firestore kann es auch zu einer Verarbeitung personenbezogener Daten in Drittländern, insbesondere in den USA, kommen. Für Firebase gelten die Datenschutz- und Vertragsbedingungen von Google. Google stellt hierfür unter anderem Data Processing and Security Terms sowie Standardvertragsklauseln für Firebase bereit.
